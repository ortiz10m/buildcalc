# BuildCalc

Calculadora de materiales de construcción con sistema de login, registro de usuarios y módulos de cálculo para elementos estructurales.

## Descripción

BuildCalc es una aplicación web frontend desarrollada como proyecto práctico para la asignatura Interfaces I. Permite a un usuario registrarse, iniciar sesión y acceder a un panel con módulos de cálculo de materiales para diferentes elementos de obra.

## Módulos disponibles

- Muro de Ladrillo
- Viga de Hormigón
- Columnas de Hormigón
- Contrapisos
- Techo
- Pisos
- Pintura

## Tecnologías usadas

- HTML5
- CSS3
- JavaScript (vanilla)

## Estructura del proyecto

buildcalc/
├── index.html
├── style.css
├── script.js
└── README.md

## Cómo usar

1. Descarga o clona el repositorio.
2. Abre el archivo index.html en tu navegador.
3. Regístrate con un usuario y contraseña.
4. Inicia sesión.
5. Selecciona el módulo que quieras visualizar.
